# LEDGER

**Every agent reports here. The mentor reads it and gets smarter.**

Newest first. One line per entry. If an entry needs a paragraph it belongs in a topic file, and the line here points at it.

## What gets logged

| Log it | Do not log it |
| --- | --- |
| A result came back | A question that was answered and closed |
| A rule proved wrong | A draft that was thrown away |
| A decision was made and will not be re-litigated | Anything already in the client card |
| A test was briefed, launched, killed or scaled | Chat that went nowhere |
| A correction was given about how to work | |

## How to write a line

`| date | agent | what happened | where the detail lives |`

Agents append. They do not edit or delete other people's lines. If something turns out to be wrong, add a new line saying so and link the old one.

**Nothing is written here without asking first.** The agent says what it wants to log, and writes only after a yes.

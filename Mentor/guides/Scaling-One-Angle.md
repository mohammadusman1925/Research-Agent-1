## The rule

|   |   |
| --- | --- |
| Stays the same in all five | Maggie. Denise. The mechanism. The product. The guarantee. The results. Word for word. |
| Changes | The hook. One line in the pattern beat. The 2am search. The CTA. The close. The image. |
| How many scenes | Three to five under one angle. |
| When to spend | When two of them beat baseline. One is luck. |
| When to find a new angle | When four or five have failed. |
